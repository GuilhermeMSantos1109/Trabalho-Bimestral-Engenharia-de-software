# Trabalho-Bimestral-Engenharia-de-software
----------------------------------------------------------
Integrantes: Guilherme mlynarczuk santos e Nycolas Ribaski
----------------------------------------------------------
Tema: Diagrama de sequência:
fragmentos alt, opt e loop
----------------------------------------------------------
Descrição do cenário: Os diagramas de sequência são utilizados na engenharia de software para representar a comunicação entre participantes de um sistema ao longo do tempo. Eles ajudam a visualizar quais ações acontecem primeiro, quais componentes trocam mensagens e quais respostas são produzidas. Neste trabalho, o cenário escolhido é o processo de login de um sistema, desde a solicitação de acesso até a verificação dos dados informados.
